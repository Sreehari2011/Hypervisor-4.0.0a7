# PORT-01 — Verbatim compaction prompt family

**Status: ☑ done** · Target: `hypervisor/context/compact_prompts.py`
· Source: `src/core/compact_prompts.py` (246 lines)

## What ports

The verbatim summarizer prompt family: `base`, `from`, `up_to`
directional templates + the resume/autonomous continuation guards +
the fixed instruction framing. These prompts are **byte-stable render
inputs** — journaled summary hashes were computed over outputs produced
with exactly these texts.

## Contracts preserved

- Byte-exact template texts (no "improvements" — a changed template
  silently breaks replay's summary-hash verification for every fold
  ever journaled, oracle included).
- Direction semantics: base (whole window), from (summary + tail),
  up_to (head + summary target).
- The verbatim-block markers the fold verifier greps for.

## 4.0 deltas

- Module moves into the context package; no import of app config (any
  size knobs become parameters with the same defaults).
- Emitted-for field: prompts record which tier invoked them (the
  journal's `direction` field already carries it).

## Acceptance tests (write on landing)

1. Byte-diff of each template against the oracle file — must be
   identical (fixture extracted from the frozen tree).
2. Round-trip: fold with each direction → summary_hash in journal
   matches sha16 of the sidecar residual.
3. Verifier: id-preservation check finds the verbatim markers.
