# agents/defs/ — expert definition files (P3)

The fifteen 3.7.3 registry experts (registry_v2.py) are re-authored here
as agent definition files: prompt, tool allowlist, model role, turn
ceiling, scope inheritance. Data, not code — editable without touching
the platform, auditable in git, spawnable on demand via the Task tool.

Re-authoring begins in P3 against the frozen 3.7.3 registry role
definitions (oracle/src/agents/registry_v2.py) per the Chapter 14
kickoff list. Nothing belongs in this directory until then.
